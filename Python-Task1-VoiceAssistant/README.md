# Voice Assistant

## Overview

This project is a beginner-friendly voice assistant developed using Python. It can listen to the user's voice, recognize simple commands, respond using text-to-speech, provide the current time and date, and perform web searches.

## Features

- Voice input using the microphone
- Greeting response
- Current time
- Current date
- Web search using Google
- Text-to-speech responses
- Error handling for unclear or unavailable speech input
- Exit command to stop the assistant

## Technologies Used

- Python
- SpeechRecognition
- PyAudio
- pyttsx3
- datetime
- webbrowser
