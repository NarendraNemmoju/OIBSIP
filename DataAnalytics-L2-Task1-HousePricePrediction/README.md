# House Price Prediction Using Linear Regression

## Project Overview

This project uses Machine Learning to predict house prices based on housing features.

A Linear Regression model is trained and evaluated using a publicly available housing dataset.

## Objectives

- Perform Exploratory Data Analysis
- Inspect missing values and data types
- Analyze the distribution of house prices
- Study correlations between features
- Select features for prediction
- Split the data into training and testing sets
- Train a Linear Regression model
- Evaluate the model using MSE, RMSE, and R²
- Compare actual and predicted prices
- Analyze model residuals
- Analyze feature coefficients

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook
- VS Code

## Machine Learning Model

### Linear Regression

Linear Regression was used to predict house prices from the available numerical housing features.

The dataset was divided into:

- 80% Training Data
- 20% Testing Data

## Model Evaluation

The model was evaluated using:

- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

## Visualizations

The project includes:

- House price distribution
- Correlation heatmap
- Actual vs. predicted prices
- Residual plot
- Feature coefficient analysis

The project demonstrates an end-to-end Linear Regression workflow for house price prediction, including data exploration, feature selection, model training, evaluation, visualization, and interpretation.
