#  Modern Calculator

A fully functional browser-based calculator developed as part of the **OASIS INFOBYTE Web Development & Designing Internship – Level 2, Task 1**.

The calculator performs basic arithmetic operations through a clean and user-friendly interface.

---

##  Project Overview

The Modern Calculator is a responsive web application that allows users to perform basic mathematical calculations directly in the browser.

The project was developed using **HTML5, CSS3, and Vanilla JavaScript** without using external frameworks.

---

##  Objective

The objective of this project is to build a fully functional browser-based calculator capable of performing basic arithmetic operations with a user-friendly button interface.

---

##  Technologies Used

- **HTML5** – Structure of the calculator
- **CSS3** – Styling, layout, and responsive design
- **JavaScript (Vanilla)** – Calculator functionality and logic

---

##  Features

### Basic Operations

- Addition (+)
- Subtraction (−)
- Multiplication (×)
- Division (÷)
- Decimal number support

### Calculator Controls

- **Clear (C)** – Clears the complete calculation
- **Backspace (⌫)** – Removes the last entered character
- **Equals (=)** – Calculates the result

### Error Handling

- Prevents division by zero
- Displays an error message when an invalid calculation is attempted
- Handles invalid or incomplete expressions gracefully

### Additional Features

- Operator chaining
- Responsive design
- CSS Grid button layout
- Interactive buttons using JavaScript event listeners
- Clean and user-friendly interface
- No inline `onclick` attributes
- Calculator logic implemented without using `eval()`
