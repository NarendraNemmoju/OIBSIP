# Iris Flower Classification Using Python

## Project Overview

This project uses machine learning to classify Iris flowers into different species based on their sepal and petal measurements.

## Dataset

The Iris dataset contains four features:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

The target classes are:

- Setosa
- Versicolor
- Virginica

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Data Analysis

The project includes:

- Loading the Iris dataset
- Checking dataset shape and data types
- Checking missing values
- Descriptive statistics
- Pairplot visualization
- Boxplots
- Feature analysis

## Machine Learning Models

Two classification models were used:

1. Logistic Regression
2. K-Nearest Neighbors (KNN)

The dataset was divided into training and testing sets using an 80:20 split.

## Model Performance

- Logistic Regression Accuracy: approximately 96.67%
- KNN Accuracy: 100%

For this particular train-test split, KNN achieved the higher test accuracy.

## Evaluation

The models were evaluated using:

- Accuracy
- Confusion Matrix
- Classification Report

## Conclusion

Machine learning can effectively classify Iris flowers based on their sepal and petal measurements. Both models achieved high accuracy, with KNN achieving 100% accuracy on the test data used in this project.
