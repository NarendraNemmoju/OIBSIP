# TaskFlow - Todo App

A professional and responsive Todo List web application developed using HTML, CSS, and JavaScript.

This project was created as part of the OIBSIP Web Development Level 2 internship/task.

---

##  Project Overview

TaskFlow is a simple productivity application that allows users to create, manage, edit, complete, and delete daily tasks.

The application uses browser LocalStorage so that tasks are automatically saved and remain available even after refreshing or reopening the page.

---

##  Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- View all tasks
- View active tasks
- View completed tasks
- Clear all completed tasks
- Display total task count
- Display active task count
- Display completed task count
- Persistent data using LocalStorage
- Responsive design
- Modern professional interface
- Keyboard support using the Enter key
- Empty-state messages
- Mobile-friendly layout
