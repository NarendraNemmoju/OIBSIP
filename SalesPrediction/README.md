# Sales Prediction Using Python

## Project Overview

This project predicts product sales based on advertising expenditure using machine learning. The dataset contains advertising spending for TV, radio, and newspaper along with the corresponding sales.

## Dataset

The dataset contains the following features:

- TV - Advertising expenditure on TV
- Radio - Advertising expenditure on radio
- Newspaper - Advertising expenditure on newspaper
- Sales - Product sales

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Data Analysis

The project includes:

- Data loading and cleaning
- Descriptive statistics
- Pairplot visualization
- Scatter plots
- Correlation heatmap
- Train-test split
- Sales prediction

## Machine Learning Models

Two regression models were used:

1. Linear Regression
2. Random Forest Regression

The models were evaluated using:

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

## Feature Importance

The Random Forest feature importance analysis shows that TV advertising has the highest importance, followed by radio. Newspaper has much lower importance.

## Conclusion

Machine learning can be used to predict sales based on advertising expenditure. The analysis also provides insights into how different advertising channels are related to sales.
