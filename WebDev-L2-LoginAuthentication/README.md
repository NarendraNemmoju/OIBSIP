#  SecureAuth - Login Authentication System

A professional and responsive Login & Registration Authentication System developed using HTML, CSS and JavaScript.

This project was created as part of the OIBSIP Web Development Internship.

---

##  Project Information

**Project Name:** Login Authentication System

**Internship:** OIBSIP Web Development

**Technology:** Frontend Web Development

**Level:** Level 2

---

##  Features

### Authentication

- User registration
- User login
- Logout functionality
- Protected dashboard
- Current user session
- Duplicate email detection

### Form Validation

- Full name validation
- Email validation
- Password validation
- Confirm password validation
- Password strength indicator
- Terms & conditions validation

### User Interface

- Professional modern design
- Responsive layout
- Glassmorphism-inspired authentication UI
- Gradient branding
- Smooth animations
- Hover effects
- Mobile-friendly interface

### Dashboard

- Personalized welcome message
- User profile information
- Account status
- Security status
- Member date
- Recent activity
- Quick actions

### Browser Storage

The application uses browser `localStorage` to demonstrate authentication functionality without requiring a backend server.
