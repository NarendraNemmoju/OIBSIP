# Basic Weather App Using Python

## Project Overview

This project is a simple Python-based Weather App that allows users to enter a city name and view its current weather information.

The application uses the Open-Meteo weather service, so no API key is required.

## Features

- Accepts a city name from the user
- Displays temperature in Celsius
- Displays humidity
- Displays weather condition
- Displays wind speed
- Handles empty city input
- Handles invalid city names
- Handles connection errors
- Converts weather codes into simple weather conditions

## Technologies Used

- Python
- Requests library
- Open-Meteo API

## How to Run

Run the following command in the terminal:

```bash
python weather_app.py
