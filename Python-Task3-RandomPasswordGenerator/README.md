# Random Password Generator Using Python

## Project Overview

This project is a Python-based Random Password Generator that creates passwords according to the user's selected requirements.

## Features

- Accepts password length from the user
- Minimum password length of 8 characters
- Supports uppercase letters
- Supports lowercase letters
- Supports numbers
- Supports symbols
- Requires at least two character types
- Validates user input
- Allows the user to generate another password without restarting

## Technologies Used

- Python
- random module
- string module

## How to Run

Run the following command in the terminal:

```bash
python password_generator.py
