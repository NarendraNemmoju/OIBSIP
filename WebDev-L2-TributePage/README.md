# OIBSIP - Web Development Level 2
## Tribute Page - Dr. A. P. J. Abdul Kalam

---

## 📌 Project Overview

This project is a professional tribute webpage dedicated to
Dr. A. P. J. Abdul Kalam, one of India's most respected scientists,
visionaries, educators, and former President.

The webpage presents his life journey, achievements, contributions,
books, inspirational thoughts, and lasting legacy through a modern
and responsive user interface.

This project was developed as part of the
**OASIS INFOBYTE Web Development Internship - Level 2**.

---

## 🎯 Project Objective

The main objective of this project is to create an attractive,
responsive, and informative tribute webpage using fundamental
web development technologies.

The project demonstrates:

- HTML5 structure
- CSS3 styling
- Responsive web design
- Modern user interface design
- CSS layouts
- Timeline design
- Image handling
- Navigation links
- Hover effects
- Professional typography

---

## 🛠️ Technologies Used

### HTML5

HTML5 is used to create the structure and content of the webpage.

### CSS3

CSS3 is used for:

- Page layout
- Colors
- Typography
- Animations and transitions
- Responsive design
- Cards
- Timeline
- Hero section
- Navigation bar

### Google Fonts

The project uses:

- Playfair Display
