# Chat Application

## Overview

This project is a simple client-server chat application developed using Python sockets. It allows a client and server to communicate with each other in real time through a local network connection.

## Features

- Client-server communication using Python sockets
- Real-time two-way messaging
- Timestamps for received messages
- Localhost communication
- Graceful disconnection using the `exit` command
- Error handling for connection problems

## Technologies Used

- Python
- Socket Programming
- datetime module
